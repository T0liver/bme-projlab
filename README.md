# bme-projlab
Jody Domingre bandája csapat Szoftverprojekt laboratórium repositoryja.

## Prototípus teszt

Erre a branchre kerülnek a játékot tesztelő függvények, osztályok, illetve az egész tesztprogram is.

A proto-kod2 branchről, amikor kész van egy nagyobb munka mergeljük erre a branchre, és így szépen elkülöníthető a munka.

**pls kódolás előtt ``git fetch && git pull``, így nem lesz annyi egymásra szerkesztgetés!**
